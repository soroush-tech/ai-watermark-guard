## ai-watermark-guard@0.1.0

First release. Finds the characters that mark text as machine-written, and the ones nobody meant to
commit, across every file in a repository and in commit messages.

### Rules

Three tiers, all on by default:

- `invisible` - zero-width space, word joiner, byte order mark, soft hyphen, U+FFFD.
- `punctuation` - en dash, em dash, minus sign, curly quotes, ellipsis, non-breaking spaces.
- `mojibake` - UTF-8 that was decoded as Latin-1 somewhere upstream.

`U+200C`, `U+200D`, `U+200E` and `U+200F` are never flagged, whatever the rules say. Persian needs
the first between the parts of a word, an emoji sequence needs the second to hold itself together,
and the last two set the direction of mixed right-to-left text. Letters are never touched, in any
script: this is not an ASCII-only rule.

### Modes

`--all`, `--staged`, `--since`, an explicit path, or - with no flag - whatever differs from the
merge-base with `--branch`. Commit messages through `--message` for a `commit-msg` hook and
`--messages` for a range in CI. Binary files are skipped by the NUL-byte test git uses; files that
are not valid UTF-8 are reported rather than scanned through a lossy decode.

### Fixing

`--fix` writes prose (`.md`, `.markdown`, `.txt`, `.text`, `.rst`, `.adoc`) and commit messages.
Code is reported and left alone: a curly apostrophe inside a single-quoted string becomes a
straight quote that ends the string, and JSON, YAML and TOML values are quoted too. Mojibake is
never fixed - the original bytes cannot be recovered from the damage, and a guess would hide the
problem instead of showing it.

`--messages` refuses `--fix`. Rewriting a commit message makes a new commit object, changing every
sha from that point on and voiding every signature over them.

### Install

Prebuilt binaries ship as optional dependencies, one package per platform, selected by `os`, `cpu`
and `libc`. Nothing is compiled and no install script runs, so `npx ai-watermark-guard` works from
cold and the tool survives an install with `--ignore-scripts`.

Supported: windows x64 and arm64, macOS x64 and arm64, Linux x64 and arm64 on glibc, Linux x64 on
musl. Anywhere else, `cargo install ai-watermark-guard` builds it.
