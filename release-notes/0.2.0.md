## ai-watermark-guard@0.2.0

The release pipeline now covers crates.io: the crate and the eight npm packages ship together
from one dispatch, pinned to a single version.

### Packaging

- The crate is published to crates.io by the same release run that publishes the npm packages,
  authenticated per run through Trusted Publishing (OIDC) - no long-lived registry token exists
  anywhere. `0.1.0` reached crates.io by hand; from this release on, the pipeline owns it.
- No dependency, MSRV, platform-package, or Node `engines` changes.
